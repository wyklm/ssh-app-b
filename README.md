# 我的安卓 SSH 工具（云端自动打包版）

自己添加/保存多台服务器 + 常用命令库（分类带说明，点一下复制或执行）。
不用在自己电脑装 Android Studio——传到 GitHub，云端自动编译出 APK 给你下载。

**B版（终端模拟器试用版）**：点服务器后弹窗可选连接模式：
- **终端模式（B版）**：全屏真终端（VT-100），能跑 vim/top，真光标、真颜色，像服务器终端一样。
- **命令行模式（A版）**：原来的"输入命令→看结果"模式（带回车直接发送 + 重要信息绿色显示）。

## App 长什么样

- **主页**：服务器列表，右上角"+ 添加服务器"自己填名称/IP/端口/账号/密码，自动保存；点一台弹窗选择连接模式。
- **指令**：常用命令按类分组（Docker容器 / 系统状态 / 服务管理），每条带中文说明；点一下填入输入框，长按或点"复制"直接复制。
- **更多**：版本说明、清空已存服务器。

## 打包步骤（手机或电脑浏览器即可）

1. 打开 https://github.com 注册/登录。
2. 右上角 +号 → **New repository**：名字填 `ssh-app`，选 **Public**，不勾 README，点 **Create**。
3. 仓库页 **Add file → Upload files**，把解压后的整个文件夹拖进去，**Commit changes**。
4. 顶部 **Actions** 标签页：首次提示就点 **I understand... Enable workflow**，等 `build-apk` 出现绿勾（2~3 分钟）。
5. 点进这次运行，底部 **Artifacts** 下载 `ssh-app-debug-apk`，解压得 `app-debug.apk`。
6. 传到手机安装（允许未知来源）。

## 想加更多服务器/命令

- 服务器：App 里直接"+ 添加服务器"即可，不用改代码。
- 命令：编辑 `app/src/main/java/com/zj/sshapp/MainActivity.kt` 顶部的 `categories`，照样子加一行，commit 后自动重新打包。
